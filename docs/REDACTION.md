# 导出脱敏说明

本仓库是用于GitHub发布的脱敏源码副本，生产技能、脚本和官方安装没有修改。

- 排除真实.env、缓存/pyc、业务数据、日志、截图及APK；未读取真实.env内容来生成公开配置。
- 删除源码和注释中硬编码的API密钥，并清空邮件授权码默认值；保留原有环境变量读取方式，敏感默认值为空。
- 手机号/账号使用10000000001等一致的演示编号，原特殊账号分支及相关测试引用同步替换，未改分支结构。
- 私人邮箱替换为example.invalid地址；不是可投递收件人。
- 车牌和设备唯一串号替换为演示值。手机型号、系统和软件版本保留真实观测结果。
- 本机绝对路径作为归档环境保留，未据此重构或创建新业务入口。

这些替换属于公开副本的隐私/配置脱敏，不表示仓库文件与生产逐字相同。docs/export-manifest.json逐项记录原文件SHA256、导出SHA256和变换类别；不包含原敏感值或映射表。重新部署必须通过用户本地受管配置补齐所需值，不能拿演示编号直接运行真实业务。
