# 敬业连接恢复助手 0.5.3

本版保留0.4的有限开关重试和原15秒认证地址上报，新增“用户登记的具体接入点”网络授权框自动确认，并适配荣耀完整分列布局及实际活动窗口变化。已配对且连接健康时任务使用现有连接，失联时电脑按原流程自动发现并核对同一手机；不会自动新配对。

1. 同包名、同签名更新，保留数据。升级后打开助手，点击“开始 / 恢复一次”。
2. 在前台批准精确位置权限并开启系统定位，点击“登记当前接入点”，核对并确认你认可的SSID和BSSID。每个接入点须分别登记，最多16个，不按同名Wi-Fi批量授权。
3. 点击“启用白名单自动确认”，阅读并确认，再在Android辅助功能设置中手动开启“敬业：已授权接入点确认”。如有受限设置提示，按系统要求由用户决定。
4. 保持原恢复服务布防。仅亮屏且未锁定、完整系统框和精确AP匹配时自动勾选始终允许并点允许。未知网络仍由用户决定。暂停、清空白名单、停用辅助功能不会清除已消耗动作预算。

开关开启、网络允许、电脑已配对和电脑当前已连接是不同状态。复制诊断中的PC_UNVERIFIED不表示电脑已经连接，使用电脑只读状态命令核实。配对记录若被删除或失效，须由用户明确授权重新配对；动态连接端口无需记为固定值。不要清数据、卸载、删除已配对设备或替换签名来升级。

0.5.3改用实际活动根窗口及其元数据核验目标，避免勾选后被其他事件窗口编号打断。事件合并200毫秒，最多6次检查、8秒；每10分钟最多3次勾选和3次允许，预算持久化。无坐标/手势兜底、不解锁、不永久循环写开关、不绕过未知网络信任。原开关恢复与地址上报源码保持不变。

详见[验收与限制](../docs/WIRELESS_RELEASE_0.5.3.md)、[原地址上报配置](ADDRESS_REPORT.md)。关机/强行停止、系统永久杀服务、任意漫游和锁屏覆盖不在本次保证内。运行仓库根目录tests/run_offline_export.py可做离线验证；test-stubs不进入APK。签名材料、SDK和私有配置不公开。
