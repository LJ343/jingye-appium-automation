# 敬业连接恢复助手 0.4

无线开关恢复未保持后，间隔60秒、120秒追加最多两次尝试；每轮最多3次写入，仍受持久化每10分钟最多3次的限制。达到上限、权限异常、写入拒绝或平台/存储故障时保护停止，不无限写开关，不绕过网络信任确认。重试预算和时间跨服务重建保留。

正常连接时由事件监听开关，15秒认证地址上报与0.3一致。电脑正常使用已有连接，失联时按原有规则发现端口并核对手机身份；不会自动进行新配对。

详见[0.4策略和验收边界](../docs/WIRELESS_RELEASE_0.4.md)、[原地址上报配置](ADDRESS_REPORT.md)。原0.3私有配置和权限通过同签名升级保留，无新增权限。升级后打开助手并按“开始 / 恢复一次”，电脑实际连接请用状态查看器核实。

运行仓库根目录的 tests/run_offline_export.py 可执行当前策略、真实持久化及协议离线测试；test-stubs不会进入APK。历史ExternalWaitReviewTest仅描述0.3，当前入口不运行它。签名材料和SDK不随源码发布，构建脚本中的路径占位符需自行审核。
